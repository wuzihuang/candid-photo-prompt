# 夏季水边抓拍（泳池 / 海边 / 户外淋浴）

仍然按 SKILL.md 的六句话写，这里只补夏季场景的专用规则。

## 硬规则

1. **一张独立照片**。可以多人，但必须同一地点、同一时刻、同一件事。只写一句 `a single standalone photograph, one continuous moment`，不要在提示词里罗列 collage、grid 之类的词，列出来反而会引导模型。
2. **所有人物一律写明 21–30 岁成年人**，成年面孔与成年比例。指定角色原作年龄偏小或外观幼态时，改为成年 COS 重构；做不到就不生成。
3. **画面重点是事件和情绪，不是身材**。机位由事件决定，不为展示身体选低角度或局部特写，不写身材描述。服装一句带过。
4. 无文字、水印、logo。

## 夏季专用选项（每类选一两个）

- **水**：湿发贴脸、肩上水珠、被闪光定住的水花、镜头上一滴水、水面反光打在下巴。
- **光**：下午侧逆光让发梢发亮、正午硬光、泳池反射光、傍晚闪光灯。
- **物件**：墨镜、化了一半的冰咖啡、揉皱的毛巾、湿拖鞋、帆布袋、防晒霜。
- **皮肤**：一天晒下来鼻尖和脸颊微红；刚出水没有妆。

## 多人

- 每个人单独一句：身份来源 + 发型 + 泳装款式与颜色 + 此刻在做什么。各人泳装不同。
- 构图不对称：一人近、一人被画面边缘裁掉一部分或略虚；避免横排站立、全员看镜头。
- 多个身份参考图时写清“第 1 张参考图是 A，第 2 张是 B”，参考图只约束脸和发型。

## COS 角色

保留发色、发型、瞳色、标志色、标志配件和性格，转译成真实泳装（连体、运动款、度假款、防晒泳衣），不把整套战斗服搬进泳池。真人皮肤、真实假发纤维、真实布料。成年规则见硬规则 2。

## 实测样例

- 泳池：男友蹲在池边用 iPhone 从腰高往下拍，她刚从水里探出头、发现他在拍而笑；下午侧逆光，池边有墨镜和冰咖啡。✅
- 海边：朋友用一次性相机闪光，另一个朋友泼水，她扭身挡水闭眼大笑；长袖防晒泳衣 + 沙滩短裤。✅
